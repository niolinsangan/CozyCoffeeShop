# CozyCup Café Website

A modern, responsive website for CozyCup Café, featuring a cozy and inviting design that showcases our coffee shop's offerings and services.

## Contributors

- **Antonio Linsangan IV** - Lead Developer
- **Espencer Badilla** - Lead Developer

## Features

- Responsive design that works on desktop and mobile devices
- Clean and modern user interface
- Interactive menu with categorized items
- Contact form for customer inquiries
- Google Maps integration for location
- Newsletter subscription
- Social media integration

## Pages

- **Home**: Welcome page with featured products
- **Menu**: Complete list of coffee and pastry offerings
- **About**: Information about CozyCup Café
- **Contact**: Contact form and location information
